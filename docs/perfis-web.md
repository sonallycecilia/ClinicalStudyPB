# Perfis contemplados na interface web

A interface web deste protótipo contempla somente três perfis:

- **Administrador**: administração de usuários.
- **Pesquisador**: estudos clínicos.
- **Coordenador**: estudos clínicos.

O perfil **Participante** não possui página, acesso de demonstração nem opção de cadastro/edição na interface web. Os campos sobre quantidade de participantes nos estudos são dados do estudo e não representam um perfil de acesso.

Observação: se o backend compartilhado continuar reconhecendo o papel Participante por exigência de outras funcionalidades do projeto, isso deve ser tratado separadamente; esta alteração limita os perfis expostos pela interface web.
